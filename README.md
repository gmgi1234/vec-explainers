# 向量三重积 · 三个交互页面

注册电气工程师（公共基础·数学）空间解析几何的自制交互说明。

| 页面 | 文件 | 讲什么 |
|---|---|---|
| ① 叉乘给面积，点乘才给体积 | `index.html` | 为什么 `a×b` 是面积向量、`(a×b)·c` 才是体积；拉滑块改高度，体积变、叉乘结果不动 |
| ② 垂直于一个方向是一整张平面 | `perpendicular.html` | 三维里“垂直于 n”是平面不是线；两平面相交得到 `(a×b)×c` |
| ③ 平行于平面 ≠ 在平面上 | `parallel.html` | 向量没有位置；直线 ∥ 平面与直线在平面上的唯一差别是点落不落在面上 |

全部为单文件 HTML，无外部依赖，手机可直接打开（拖动旋转、滑块调参）。
