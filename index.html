① 画面里都有什么

a、b 在地面上，它们围出的平行四边形就是面积。n = a×b 竖直立起来，长度等于这块面积——它是“面积加朝向”钉在一起的一根钉子。

c 斜着离开地面，(a×b)×c 由 n 和 c 叉出来。半透明的六面体是 (a×b)·c：面积 × 高 = 体积。

钉子 × c（叉乘）→ 向量，必须垂直于 n，所以只能在地面方向上；c 抬多高它都不变。
钉子 · c（点乘）→ 一个数，专门取“c 升起来多少”，面积乘它就是体积。

画面里有两张平面，别搞混：平面(a,b) 的法线是 a×b；平面｛a×b, c｝ 的法线是 (a×b)×c。后一张张在 n 和 c 上，而 n 垂直于前一张——所以这两张平面互相垂直，(a×b)×c 作为后者的法线，自然就躺在平面(a,b)里。

② 叉乘为什么给不了体积

量纲：|a×b| 是长度²（面积），体积是长度³，少一次乘法就永远差一个量纲。

方向：三维里“垂直于 n”不是一个方向，而是整整一张平面——拉“抬离地面”那个滑块，它会升空，但方向一个字不改。

所以准确的说法是：(a×b)×c 平行于地面，而不是“落在”地面上。只有从原点画出来时，它才恰好铺在那张面上。

③ 平行于平面 ≠ 在平面上

向量没有位置，只有方向和长度；点是位置，没有方向。所以对向量只能说“平行于某个平面”，对点才能说“在这个平面上”。

直线与平面的两条判定，差别就在这一点
直线 ∥ 平面：s·n = 0，且直线上一点不在平面上
直线在平面上：s·n = 0，且直线上一点在平面上

④ 记住这一句

叉乘管方向，点乘管投影。想要体积，必须是“面积 × 高”，所以只能走点乘那条路。
